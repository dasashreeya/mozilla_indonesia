Lost in Transcription — Indonesian–JavaneseAudit, 7 Sept 202618 days to deadline

The oracle sits on the leader

A perfect combination of the nine systems this project already owns would score 0.216 on the public test set. The leader is at 0.2196. First place is not beyond us — it is exactly where our ceiling already is, which means the work is better base systems, not cleverer combination. And five of the twelve training arms that were designed to find them have never been run.

Public test WER — lower is better

Every value on this axis is a real measurement except the oracle, which is the 0.1641 word-level oracle mapped through the project's recorded local-to-public offset of +0.052.

The gap between a perfect recombination of everything we own and first place is 0.0035 — roughly a fifth of the smallest difference the 509-clip validation fold can even resolve. That is the whole strategic picture in one number.

The core finding

The recipe that was declared not to transfer was never run

scripts/modal_recovery.py:386 defines twelve Wave 1 training arms. experiments/results.csv and the knowledge base report seven. The five with no result anywhere are the ones that mattered most — and every one of them is already coded, tested and launchable.

ArmWhat it testsStatus
arm-lora The verbatim 1st-place Pasketti recipe: LoRA r=16 α=32 at lr 1e-4, 3 epochs, SpecAugment, keep every checkpoint never run
arm-prompt Whether the context prompt worth −0.025 before training survives fine-tuning never run
arm-extra External data alone, unconfounded — preempted at step 94 of 636 died
arm-javtts East Javanese TTS from Lumajang, which borders Jember data not fetched
arm-alldata Both external corpora together data not fetched

Every arm that was reported ran the train_recovery.py defaults instead: full fine-tune, lr 1e-5, one epoch, cosine. So the seven reported arms varied data, not method — and the method was then declared not to transfer, on the strength of SpecAugment (one component of it) and beam search (not part of it at all).

Ordered by how much each changes what to do next

Six more things the audit found

01

The local-to-public calibration pairs two different models

The +0.052 offset comes from a table pairing local 0.2685 with public 0.32590. Those are not the same run: 0.2685 is qwen-jav-holdout-v1 on the recovery-jav1 manifest with 20 sessions held out; 0.32590 was submitted from qwen-recovery-v2-fold5, which trained on all 208.

Every target since inherits that offset, including the 0.148 the “not reachable” verdict is measured against. One decode pass fixes it.

02

The validation fold is weighted wrong for the task

The holdout is 37.96% Javanese by reference words. The test set is about 49%. Reweight to the test composition and base Qwen's local score predicts its public score to within 0.0006 — a far better instrument than the one in use.

03

SpecAugment coming out null was read backwards

SpecAugment is a regulariser. It does nothing when a model is not overfitting. Ten hours of audio, ~2,300 windows, ~550 optimizer steps per epoch, a 1.7B model: this system is data-starved, not over-fit. The right response is more and more varied data — speed perturbation, the standard low-resource multiplier, has never been tried.

04

No model has ever trained on all the in-domain data

The submitted model held out development conversation 5: 294 of 372 dev clips — 79% of the only in-domain code-switched labelled audio that exists. A final fit over 100% of it is the most certain unclaimed gain in the repository and needs no new method at all.

05

Training-set alignment has never been audited

Session 35 sits at 0.9352 WER against 0.16–0.44 for its nineteen neighbours, and was diagnosed as a timestamp misalignment rather than a recognition failure. It is validation-only. Nothing has ever checked the 188 training sessions for the same defect — one decode pass, and it would explain why eight recipe variants all landed within 0.018 of each other on Javanese.

06

The competition archives were one git add -A from a public push

The Jember corpus (285 MB, CC-BY-NC-SA) and the development archive sat untracked but unignored at the repository root; .gitignore only covered data/*.tar.gz. The rules forbid redistributing competition data. Fixed in this commit.

Live Hugging Face survey, 7 Sept

Two corrections to the model plan

VibeVoice is blocked by the runtime

VibeVoice-ASR-HF declares transformers 5.3.0.dev0. The official runtime pins 4.57.6 with a hard constraint of <5. The non-HF repo needs a vLLM plugin version the runtime does not ship. It was investment priority 2; its Javanese pretraining share is 0.0025%. Drop it.

The survey missed the CTC family

facebook/w2v-bert-2.0 — MIT, 580M, pretrained on 4.5M hours across 143 languages including Javanese and Indonesian. It is the only architecture that can use the kenlm and pyctcdecode the runtime already ships. Nothing in the repo uses either.

Why a language model, specifically

46.7% of Javanese errors on already-seen words are the correct word under the wrong transcription convention — not a mishearing:

18× ning → neng 14× nggak → gak 13× kaya → kayak 11× karna → karena 10× nang → neng 6× wektu → waktu

Context-free rewrite maps are measured dead at +0.09 to +0.23, for a precise reason: the model emits gak correctly 167 times and wrongly 89 times, so a global rewrite loses 78. An n-gram LM trained on the Jember and development transcripts encodes those same frequencies conditioned on context. It is the conditional version of the intervention that failed unconditionally — which is why it is the one lever aimed straight at the largest error class.

Five stages, in dependency order

The programme

0

Fix the instrument — no training

Nothing downstream is trustworthy until the measuring stick is. All of it is decode passes.

  • Score the model that actually scored 0.32590 on the mixed fold, so the calibration is a measurement
  • Report every WER at both 37.96% and 49% Javanese weighting; select on the 49% column
  • Decode all 188 training sessions, rank by WER, hunt the session-35 boundary-lag signature
  • Re-measure the context prompt after fine-tuning — it is worth 0.025 before
A

Close the recipe gap

Method changes, not data changes. arm-lora and arm-prompt need no new code — one modal run. Then the full-fine-tune LR sweep the project never did (1e-5 today; try 3e-5 and 1e-4), speed perturbation, and a noise/RIR arm.

Finish with checkpoint averaging. model_soup.py was written and tested and has never produced a result row — and souping is what separated 1st from 3rd in the reference competition, where 2nd place averaged eighteen runs. It is free at inference.

B

Get the Javanese data, and condition on style

Fetch the East Javanese TTS corpora. Then the trick that makes them safe to use: extend the training target's existing tag slot so it encodes corpus style, not just language — Jav for Jember, Javtts for read speech — and always decode with the in-domain tag. External audio trains the encoder; only in-domain rows teach the decoder how Jember spells things.

This reuses machinery that already exists and already has tests, and it is the honest fix for the earlier “OpenSLR transferred negatively” result, which had no target-style adaptation stage at all.

C

Build a system that fails differently

The finding that should have driven everything: adding base, zero-shot Whisper to three Qwen systems moves the word oracle from 0.2267 to 0.1882. The worst single system contributes the most new coverage. Diversity, not accuracy, is the scarce resource.

  • Fine-tune Whisper large-v3 — train_whisper_recovery.py exists and has never produced an evaluated checkpoint
  • Build the CTC system: w2v-BERT 2.0 plus a character CTC head, decoded through pyctcdecode with a 4-gram KenLM over the Jember, development and Panjebar Semangat text
D

Model the convention explicitly

Greedy and beam-4 tie on the 1-best, which says nothing about the n-best list. Emit 8–16 hypotheses per clip and rescore against the KenLM. Measure the n-best oracle before building the rescorer — one decode pass says whether the headroom is there, and if it is not, skip the machine.

E

Combine, then fit on everything

Held-out-validated selector over the three diverse systems. Then the final fit on 100% of labelled in-domain data — all 208 Jember sessions, all 372 development clips, external corpora capped, style tags in place. No holdout: the recipe is already chosen by then.

18 days, 3 submissions per person per 7 days

What to expect

Stages 0, A, B and E are low-risk and mostly measure things that should already have been measured. That block alone should land around 0.27–0.30 public — a clear improvement on 0.3259 and not a winning score. Reaching the leader requires Stage C or D to work.

Beat the leader's 0.2196

35–45%

Needs one genuinely diverse system plus an honest combination pass — not a new state of the art.

Break 0.20 public

15–25%

Genuinely requires hypotheses no current model produces. Stage C and D both have to land.

These are judgements, not measurements. They sit above the earlier “not reachable” reading for one reason: three of the arms designed to test the question have never been run. The promotion gate stays strict — no full submission unless the 49%-weighted holdout improves by 0.015 or more, since run-to-run noise is ±0.002 and only differences above ~0.015 are resolvable on 509 clips.

Not revisited

What the audit leaves standing

These survive intact and should not be re-litigated:

  • Blanket lowercasing costs +0.023. Never lowercase — the MDC scorer compares casing as written.
  • Hyphen-to-space costs +0.056.
  • Context-free spelling maps cost +0.09 to +0.23; vocabulary snapping +0.0131.
  • The Javanese diacritic convention as implemented is correct — development writes Jember's accented forms plain 99.8% of the time.
  • Duration matching by cutting short Jember segments is harmful (+0.0066).
  • Beam search over greedy is +0.0003 on the 1-best.
  • Base Whisper large-v3 is the weaker standalone model — but it is the strongest ensemble contributor.
  • The annotation-inconsistency floor is 0.02–0.05 and does not block the target.
